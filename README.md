# Portfólio Jotape

Site de portfólio desenvolvido como projeto do curso Transforme-se.

**Site publicado:** https://j0tt4pp3.github.io/portfolio/

> **Aviso:** este é um projeto acadêmico, feito para praticar HTML, CSS e acessibilidade. Ele funciona como um **modelo** de portfólio e não é o meu portfólio definitivo. Os textos, os projetos e as imagens são ilustrativos e não representam trabalhos reais.

## Sobre o projeto

O layout foi planejado no Figma, com versões para celular e desktop, e depois implementado em código. O site tem as seções de apresentação, sobre, projetos, contato e rodapé.

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis, Flexbox, Grid, media queries e animações)
- Formulário de contato integrado com o Formspree
- GitHub Pages para a publicação

## O que foi trabalhado

- **Estados de interação:** links, botões e cards respondem ao mouse com `:hover`.
- **Navegação por teclado:** os mesmos elementos têm `:focus-visible`, com contorno bem visível, e recebem o mesmo efeito do hover.
- **Consistência visual:** todos os elementos clicáveis seguem o mesmo padrão de resposta (cor, preenchimento e leve aumento).
- **Acessibilidade:** estrutura semântica, textos alternativos nas imagens, rótulos nos campos do formulário e contraste de cores.
- **Responsividade:** o layout se adapta a celular, tablet e desktop.
- **Detalhes de design:** tema escuro, gradiente nos títulos, cabeçalho fixo com desfoque e favicon próprio.
